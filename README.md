# 학교 업무 원샷

교사들이 자주 쓰는 출판사 / 나이스 / 하이클래스 등을 한 페이지에 모은 포털.

## 실행
- `index.html`을 더블클릭해서 브라우저로 열면 됩니다 (설치 불필요).
- VS Code Live Server로 열어도 됩니다.

## 구조 (유지보수형)
```
index.html        뼈대
css/style.css     디자인
js/app.js         검색/필터/즐겨찾기 로직
data/sites.json   사이트 목록 (여기만 수정)
```

## 사이트 추가 방법
`data/sites.json`에 아래 형태로 추가:
```json
{
  "id": "고유id",
  "name": "사이트 이름",
  "desc": "한줄 설명",
  "url": "https://...",
  "category": "업무시스템",
  "tags": ["검색어", "별칭"]
}
```
- `category`에 새 이름을 쓰면 자동으로 새 섹션+필터 버튼 생성
- `tags`에 별칭(예: "neis", "T셀파")을 넣으면 검색이 잘 됨

## 기능
- 실시간 검색, 카테고리 필터
- 즐겨찾기(★, localStorage 저장), 즐겨찾기만 보기
- 다크모드, 반응형, 파비콘 자동 표시
